Frenzy Protocol

Um FPS 3D roguelike frenético para dispositivos móveis.

Visão

Frenzy Protocol combina:

- FPS 3D de alta velocidade
- combate agressivo
- movimentação rápida
- dash e habilidades
- armas com estilos diferentes
- salas e encontros variados
- progressão roguelike
- chefes
- runs diferentes a cada partida

Plataforma

- Android
- iOS

Estado atual

🚧 Pré-produção

O primeiro objetivo é criar um protótipo jogável com movimentação FPS, câmera, controles touchscreen, uma arena, armas e inimigos.

Direção

O jogo busca uma experiência rápida, intensa e recompensadora, mas terá identidade própria em personagens, mundo, armas, inimigos, mapas e sistemas.
